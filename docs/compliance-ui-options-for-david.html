Compliance UI — how staff chase what’s missing

You flagged calling the same tenant twice (COI, then plates an hour later). Below: what we heard, action items, how this maps to FMS, and three layout options. Pick one and we implement.

What you said (problem)

  • Insurance and License plates are separate lists — same customer (e.g. AA&D Transport) can appear on both, so compliance staff call twice about different gaps.
  • Customers already shows COI status; Compliance also shows expired COIs — feels duplicated.
  • Preference: one compliance view that lists everything missing per customer (COI, plates, lease / renewal, etc.).
  • Nav: put Compliance under the Customers area (Customers + Compliance), not three unrelated top-level queues.
  • Customer detail is good (lease, money, COI) — add vehicles / access (gate code + plates; N vehicles from Book Now, including “submit later”).
  • Longer term: automation (email / SMS) for missing COI, plates, lease items — similar to how FMS reaches customers.

FMS parallel (why both list + worklist)

In FMS you open a customer for the full file (contact, yard, inventory, phone, email, then drill into details). Compliance people also need a day-to-day work queue — not every tenant, only people who still owe something.

Customers = directory / full file (FMS customer list + detail).

Compliance = “who do I call today?” — one row per customer with all gaps listed (COI + plates + lease), so one call covers everything.

That answers your question: keep both — profile for “is this file complete?” and a compliance worklist for the person whose job is chasing gaps. Same data; different job.
